# 🚀 AI Portfolio Generator

An AI-powered web application that instantly transforms plain-text resumes into stunning, interactive HTML portfolios. 

## ✨ Features
*   **Intelligent Parsing:** Powered by the Google Gemini API to accurately extract and structure resume data.
*   **Modern Design:** Outputs a gorgeous web portfolio featuring glassmorphism, gradient accents, and dynamic hover animations.
*   **Error Handling:** Includes built-in safety checks to ensure consistent AI formatting and reliable portfolio generation.
*   **User-Friendly:** Simple, clean upload interface built for a seamless user experience.

## 🛠️ Tech Stack
*   **Backend:** Python, Flask
*   **AI Integration:** Google Gemini API
*   **Frontend:** HTML5, Modern CSS3

## 🚀 How to Run Locally
1.  Clone this repository to your computer.
2.  Install the required dependencies from the requirements file.
3.  Create a local `.env` file and securely add your Google Gemini API key.
4.  Run the application using Python and open the local server in your web browser.
